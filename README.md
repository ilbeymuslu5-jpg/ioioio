# Nazar Sarayı – Padişah Slot 🧿

Türk temalı, mobil uyumlu bir slot (kumar makinesi) oyunu. **Sadece eğlence amaçlıdır; sanal akçe kullanılır, gerçek para yoktur.**

## Oynamak
`index.html` dosyasını tarayıcıda (tercihen telefonda) açın.

## Özellikler
- 5 makara × 3 sıra, 10 kazanç çizgisi, HTML5 Canvas ile çizim
- Semboller: 👑 Padişah (joker), 🧿 Nazar (scatter), 🐈 Van Kedisi, 🌷 Lale, ☕ Türk Kahvesi, 🫖 Çay, 🥨 Simit, 🍬 Lokum
- 3+ 🧿 → **Çarkıfelek** bonusu (×2 – ×50)
- Hicaz makamından kazanma melodisi, titreşim, altın/nazar parçacık efektleri
- Otomatik çevirme, bakiye kaydı (localStorage), günlük 1.000 akçe hediye
- Arka plan görseli Canva ile üretildi (`assets/bg.png`)
- Simüle edilmiş geri ödeme oranı ≈ %95, bonus ≈ her 80 çevirmede bir
