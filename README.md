# ioioio
## Kılıç Avı

Tek dosyalık, mobil uyumlu basit bir dokunmatik oyun. `index.html`'i tarayıcıda aç.

- 3×3 tahtada çıkan silahlara kaybolmadan dokun: gümüş kılıç +1, eldiven +2, altın kılıç +5
- Kahverengi çarpıya dokunma, bir silahı kaçırma: ikisi de can götürür (5 can)
- Arka arkaya 10 isabette çarpan artar, oyun zamanla hızlanır, en iyi skor cihazda saklanır

Grafikler: [Kenney](https://www.kenney.nl) RPG UI paketi (CC0), `gemini` reposundan alındı.
